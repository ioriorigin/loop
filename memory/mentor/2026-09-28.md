## 盲点

### 【主】作っている物の定義が、関門を通過した後で変わった。関門は、変わった後の物について一度も開かれていない

loop は 09-25 に「関門 G1〜G4 を通るまで作らない」と決めた（CLAUDE.md §5b、`venture/DEMAND.md` §3）。通ったのは「AI エージェントで Blender を操作する日本語の道具」である（`venture/ASKS.md:1950` もいまだにそう書いている）。
作っているのは「FBX 改変コマンド3本」である。**関門は「作る前」には効いたが、「作っている途中で物が変わったとき」に開き直す規定がどこにも無い。** 本のときも同じだった。題材は途中で何度も変わったが、需要は一度も測り直していない。

いま作っている物で開き直すと、次のようになる。
- G1: ¥1,000 の単機能品は複数ある。
- G4: 相場は ¥1,000 で、しかも GUI である。¥4,700 で年306件は、どこからも導けない。

### 【副】ターゲットの利用者は、引数を持つコマンドを打てない側の人である

§8.2 が見つけた需要は「Blender 不要」、つまり操作の複雑さを避けたい人だった。
README はその人に PowerShell、`cd` とドラッグ、71文字の定型の前置き、引数の名前、それもメッシュ名・キー名をカンマ区切りで二重引用符に入れた形を求めている（`venture/blender/README.md:40, 63-82`）。
AI を抜いたことで、「Blender を開くより難しい」という第11回の懸念は**悪化した。** AI があれば、少なくとも引数は AI が埋める設計だった。
