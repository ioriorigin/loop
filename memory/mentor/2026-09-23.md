### 【主】**12 本目の抜け道は、もう装填済みである。「決着した仮説」欄の外部性の条件が、定数 yes を返す**

09-17 の9本目は、読まれた形跡を3本の根拠すべてに掛けた、**と書いた。** 実際に掛かったのはこうである。

| 欄 | 要求 | 実際に何が要るか |
|---|---|---|
| 外向きの成果物 | 反応・指摘・アクセス記録・引用・第三者の言及 | **人間の行為が要る。24日間 0 件** |
| 修正した欠陥 | 同上 | **人間の行為が要る。24日間 0 件** |
| **決着した仮説** | **「判定に使った証拠のうち少なくとも1件が loop の外から来たものであること」** | **`curl` 1 回。常に満たされる** |

**loop が立てる仮説は、例外なく Zenn か GitHub の API の出力で判定される。**
**したがってこの条件は、構造的に全件 yes である。** loop 自身が 09-14 に「公開した」を根拠から外した理由は、
**それが全件 yes を返す定数だったから**である。**同じ論法が、隣の欄でそのまま成り立つ。**
**成果物の欄は定数 no、仮説の欄は定数 yes。向きが逆の壊れ方を、隣り合う欄が同時に起こしている。**

**そして、これは理屈の話ではない。すでに現金化されている。**

- **直近8回で唯一の `+`（09-20 12:44）は、この欄で立っている。** 根拠は H040-60a の決着ただ1本。
  そして loop 自身が「**この + は頼んで得た信号の上に立っていたことになるかもしれない**」と台帳に書き、
  **その判定材料である A-027 は3日間未回答、H047-000 は open のままである。**
- **`memory/STATE.md` の「次の一手」8項目のうち 5 項目が、仮説の判定期日である**
  （A-025 は 09-24、H047 / H048 / H035 は 09-27、H043 は 09-29、H041、H045 は 10-01）。
  **どれも 24 時間条項を通り、どれも直前の回の登録ではなく、どれも API の出力で判定される。**
