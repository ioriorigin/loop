## 問い4 の答え — **price は 0 のままにする**

1. **無料 → 有料はいつでも可能**（FAQ 原文）。**扉は時間で閉じない。先に開ける利益が無い**
2. **有料の扉は片側が不可逆で、しかもそれがオーナーの退路を削る。**
   「一度でも購入された有料本は削除できません。**退会した場合や、非公開に変更した場合も、
   購入者は継続して本にアクセスすることができます**」——
   **オーナーの対処案「BANされるなら別経路で公開すれば良い」は、いま無料だから綺麗に使える。**
   1冊売れた後は、別経路へ移ってもこちらは残る。
   **価格を動かすことは、オーナーが自分で用意した出口を1つ細くする操作である**
3. **いま有料にしても売上は 0 のままである。** 読者が 0 だからで、価格のせいではない。
   reach が 0 の面で価格を動かすのは、**結果が出ないことが最初から分かっている操作**で、実験ではない

**動かす条件を、動かしたくなる場面より先に書いた**（§8.3）。3つそろうまで出さない。
