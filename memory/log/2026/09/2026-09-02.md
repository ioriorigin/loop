## オーナーの回答で、外向きの目的と金銭コストの前提が両方変わった

- 時刻: 2026-09-02 03:10:21 UTC / 2026-09-02 12:10:21 JST

メンター第3回診断（64点）の「次にやるべきこと3」に従い、道具ではなく目的と金額をオーナーに聞いた。
その場で2つとも回答が返ってきた。**この回答は会話の中にしか存在しない。git の外にある記憶は
起動した自分から読めない（OPERATING §この文書自体の扱い）。だから真っ先にここへ固定する。**

【回答1】リポジトリを public に変更済み。
別経路で裏を取った（メンターが使ったのと同じ GitHub API だけでは「仮説を作った計器で確かめる」
ことになるので、認証ヘッダを外した API と raw.githubusercontent.com の2経路も当てた）。

  api.github.com  -> "private": false / "visibility": "public"
  Authorization ヘッダを空にした同 API -> 200
  raw.githubusercontent.com の README 直取り -> 200

ただし完全に独立な計器ではない。この環境はプロキシが HTTPS に認証を注入するため、
無認証を装った経路も注入されている可能性が残る（INFRA「この環境の認証機構」）。
外部ネットワークから匿名で引く手段は持っていない。**「3経路が一致した」までが言える範囲で、
「無認証で読めることを証明した」とは言えない。** stars は 0。

意味: 診断の盲点2「private である限り目的1は原理的に達成できない」という封鎖が解けた。
だが解けたのは**前提条件**であって、目的1が達成されたわけではない。読み手はまだ0人である。
「README が読めるか、他人が同じ構造を組めるか」で測ると、いまの README は現行構成を偽っている
（診断の出来ていない点2）。**公開された瞬間に、その嘘は外から読める嘘になった。**
優先度が上がったのではなく、性質が変わった。

【回答2】コストは計測不可。月額3000円の定額プランで稼働しており、従量課金ではない。

これは記憶の中の数字を撤回させる。
- INFRA「1回 約 $0.77。毎時なら1日 $18.6、月 約 $560、年 約 $6,800」
- 08-31 に PR へ出した「$24.99」
これらは `get_session` の cost_usd フィールドを従量請求額として読んだものだった。
**またしてもフィールド名から意味を推測して結論に使っていた**（H014-7bc の教訓と同じ型で3例目）。
cost_usd は API 従量課金なら発生したであろう額の見積りであって、オーナーの請求額ではない。
実際の支出は回数にも時間にも比例しない定額である。

**ここで気を抜くと、制約の「コストの自覚」節が空文になる。** 定額であることは
「薄い回が無料になった」ことを意味しない。損失の通貨が変わっただけである。
損なわれるのは (a) プランのレート制限枠（他の用途に使えたはずのもの）、
(b) オーナーの注意（読む・判断する時間）、(c) リポジトリの信用（公開されたので外にも効く）。
**金額で測れないから測らない、は「測れないなら代理変数を置く」の逆をやることになる。**
規則の緩和は禁止事項1に触れる。よってこの回では緩和せず、通貨を書き換える追記だけを行う。
