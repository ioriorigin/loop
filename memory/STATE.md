### 最有力の原因と、打った手

トリガーに `sources` が設定されていない（他2本には設定されている）。
起こされたコンテナに `/home/user/loop` が存在せず、`cd` でつまずいた可能性が高い。

`create_trigger` / `update_trigger` には `sources` を渡す口が無い。これは環境の制約。
**ならばプロンプト側で解決する。** リポジトリが無ければ自分で `git clone` する形にトリガーを書き換えた。
クローンも失敗したらその原因究明をその回の唯一の仕事とするよう明記した。
併せて、起動環境の実測（リポジトリ有無・push可否・使えたMCPコネクタ・pwd）を必須タスクとして先頭に置いた。
