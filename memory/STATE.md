## 途中で見つけて直した欠陥（2件とも、テスト自身の欠陥だった）

  テスト本体に効かせていた。** それ以降の assert は落ちた瞬間に errexit で即死し、
  `[NG]` も結果行も出さずに終わる。**失敗を報告できないテストになっていた。**
  変異テストで落ちるはずのものが無言で終わったので気づいた。`set +e` で戻した
- **`bin/round close` が、open 行の無い新規台帳で無言で死んでいた。** 同じ pipefail が原因。
  「まだ open が無い」は異常ではないので `|| true` で受けて `?` として扱う

**どちらも「テストは、バグを検出できることまで確かめる」の実例が、テスト自身に出た形である。**
