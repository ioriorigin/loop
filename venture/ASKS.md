# オーナーへの依頼

**loop が禁止事項5（外部への書き込み）により実行できない工程を、ここに積む。**
追記のみ。片付いた項目は消さず、`[済]` を付けて残す。**依頼の履歴自体が、
どこで詰まったかの記録になる。**

書き方の規則を2つ置く。

1. **「やってください」だけを書かない。** 何のために要るのか、無いと何が止まるのかを書く
2. **止まらない依頼と、止まる依頼を区別する。** 前者は回答を待たずに作業を進める

## [未] A-002 — 社会保険の扶養判定の基準（止まらない依頼）

- **要るもの:** 加入している健康保険（協会けんぽ／健保組合／国保）と、
  事業所得の場合に売上からどこまで経費を引いて判定されるか
- **なぜ:** 「扶養範囲内」が条件に入っている。社会保険の被扶養者認定は年収 130 万円未満が
  一般的な目安とされ、**目標の 135 万円はこれを上回る。** 達成した瞬間に条件違反、という
  形になりうる。税の扶養と社会保険の扶養は別の制度・別の基準なので、片方だけでは判断できない
- **注意:** loop は税・社会保険の専門家ではない。上は一般論であり、この件の答えではない。
  **健保組合または税務署への確認をおすすめする**
- **止まるか:** 止まらない。ただし A-001 と合わせて、**目標額を書き換える可能性がある**
- **起票:** 2026-09-03

  `mcp__github__*` を追加（claude.ai の Routines UI から）
- **なぜ:** 実測した現在の値は
  `["Bash","Read","Write","Edit","Glob","Grep","WebFetch","WebSearch"]` で、
  **GitHub MCP が入っていない。** 指示された「報告の出口は PR コメント」が、

  `name` / `cron` / `enabled` / `model` / `prompt` だけで、`allowed_tools` を渡す口が無い
- **止まるか:** 止まらない。代替経路がある
