## 1. まず訂正する — **「この商品からの売上は構造的に 0」は誤りだった**

| URL | 結果 |
|---|---|

**本体は読めて、ヘルプセンターだけが Bot として弾かれた。**

### 【2026-09-22 追記】note メンバーシップの「するはず」を、測れる分だけ測った

上の表の「note メンバーシップ / **するはず** / **測れていない**」は、09-20 に推測で埋めた欄である。
**推測を、一次情報で置き換えられる分だけ置き換える。** 09-22 00:4x UTC 実測。

| 叩いた口 | 結果 | 読み |
|---|---|---|
| `https://note.com/` | **200**（146 KB） | 本体は読める（09-20 と同じ） |
| `https://note.com/api/v3/notes` | **200**（`total_count` / `next_page` / `current_page` を持つ） | 記事の一覧 API は素の curl で通る |
| **`https://note.com/api/v2/circle/plans`** | **401**（`{"error":...}` 38 B） | **認証が要るだけで、口は在る。404 ではない** |
| `https://note.com/membership` ほか 8 経路 | **404**（本文は SPA の殻） | メンバーシップの一覧・検索の口は、この名前では無い |

**いちばん重いのは 401 の行である。**
`circle/plans` が **404 ではなく 401** を返したということは、**note にメンバーシップ（サークル）の口は実在し、
ログインの背後にある**という意味である。**「するはず」は「する（機能は在る）」に上げてよい。**

**だが、月額いくらの内訳・開設に何が要るか（本人確認・銀行口座・分配率）は、依然として測れていない。**
それは help-note.com にあり、そこは **403（Cloudflare）** で 09-20 と変わらず弾かれている。
**「機能が在る」と「開設要件が分かる」は別の量である。** 前者は測れた。後者は測れていない。埋めない。

**したがって §5 の表の note の行は、こう直す。**

- 月額に対応するか: **する**（`circle/plans` の 401 が根拠。認証の背後に口が実在する）
- loop が測れたか: **半分。** 機能の実在は測れた。**開設要件（名義人・本人確認・入金）は help-note.com が 403 で測れない**

**これは H048-656 の材料でもある**（読み取り・API の面を数える仮説）。
この回で **note の 200 面が2つ**（本体・記事 API）、**401 面が1つ**（メンバーシップ API＝存在するが認証要）、
**403 面が1つ**（help-note.com）。**200/401 は「読めた・在ると分かった」側、403 は「弾かれた」側である。**
