### 8.2 答え — **price は 0 のままにする**

理由は3つで、**どれも上の実測から出る。**

1. **無料 → 有料はいつでも可能である。** この扉は時間で閉じない。**先に開ける利益が無い。**
2. **有料の扉は片側が不可逆で、しかもそれがオーナーの退路を削る。**
   1冊売れたら削除も退会も非公開化も効かない（上の原文）。
   **オーナーは 09-17 に、規約の残余リスクへの対処をこう述べている**——
   「**もしBANされるのであればZenn以外の別経路で公開すれば良い**」。
   **その退路は、いま本が無料だから綺麗に使える。** 1冊でも売れた後は、
   **退会しても購入者は Zenn 上の本にアクセスし続ける。** 別経路へ移っても、こちらは残る。
   **価格を動かすことは、オーナーが自分で用意した出口を1つ細くする操作である。**
   これは規約の判断を蒸し返す話ではない。**loop が撃とうとしている操作の副作用の話である。**
3. **いま有料にしても、売上は 0 のままである。** 読者が 0 だからで、価格のせいではない。
   reach が 0 のときに price を 0 から動かすと、**変わるのは売上ではなく「無料で読める」という
   唯一の摩擦の無さだけである。** 失うものだけが確実で、得るものは仮定の上にある。

**これは「決められないので先送り」ではない。** 3つとも、**この回に測った一次情報から出ている。**

### 8.3 いつ動かすのか — **条件を、動かしたくなる場面より先に書いておく**

09-17 に「**判定基準を、判定したい場面より前に書くことには、この効き方がある**」と書いた
（禁止事項5 の解除を、14日前に書いた基準がそのまま判定した）。**同じ形にする。**

**次の3つが全部そろったら、価格の案をオーナーに出す。** そろうまでは出さない。

- **(a)** 上の 2（退路が細くなること）を**オーナーが承知していること。**
  規約の判断は 09-17 に済んでいる（A-021）。**ここで要るのは判断のやり直しではなく、
  「有料にすると別経路へ移る手が一段効かなくなる」という一文が届いていることだけである**
- **(b)** 本の `liked_count`、または loop の依頼以外の経路からの反応が、**1 件以上あること**
  （いまは本 0 / 記事 1（出所未判定・H047-000））
- **(c)** 特商法表記と事業者番号について、オーナーが「**該当する／しない**」を答えていること

**(b) が要る理由を書いておく。** reach が 0 の面で価格を動かすのは、
**結果が出ないことが最初から分かっている操作**である。それは実験ではない。

- 印の無い有料本の最高いいねは **636**（`reputeless/standard-cpp-for-competitive-programming`、¥1,000）。
  **印のある本には、いいね 3 の本が3冊ある**（`goshouhiro/utokyo-engineering-physics-*`、¥300）
- **つまり、いいねの単調関数では印の有無を再現できない。** 印は**いいねと独立の情報を運んでいる**

**独立の情報が何であるかは、Zenn が公開していない。**
FAQ の配信チャンク（`sales` カテゴリ全 15 問を含む全 39 問）に `ベストセラー` の語は1件も無く、
Zenn 上の記事検索でも運営の説明は見つからない。**「売上に由来する印らしい」までが言えることである。**

**不利な材料も書く。無料の本に4冊、印が付いている**
（`shu223/monetization` 404 / `flutteruniv/flutter-textbook` 341 / `sprout2000/...` 281 / `ys/...` 249）。
**無料の本は売れない。** 「かつて有料で、あとから無料にした本」なら説明が付くが、**外からは確かめられない。**
**印＝売上と断定しない。** 言えるのは「いいねでは説明できない」までである。

### 9.4 問い2（月 43〜259 冊は現実的か）に、何が言えるようになったか

**冊数は依然として測れない。** 出たのは**基準率**である。

> **棚に並ぶ有料本 1,430 冊のうち、売上に由来すると思われる印を持つのは 162 冊（11.33%）。
> 残りの 88.67% は、何年置かれていても印が付いていない。**

そして印のある本の価格の中央値は **¥1,000** で、§3 の表ではそれが **130 冊/月**（135 万 = 受取と読む場合）にあたる。
**この2つを並べると、問い2 の形が変わる。**

- 09-20 の形: 「月 130 冊が現実的かどうか、外から確かめる手段が無い」
- **いまの形: 「有料本の 11.33% しか届かない側に入れるかどうか」。**
  **分からないことは変わらないが、分からなさの種類が変わった。**
  正規化されていない絶対数（月 130 冊）から、**棚の中で観測できる比率**へ移った

**ここで「11.33% に入れる／入れない」を判定しない。** 印の定義が非開示である以上、
**この基準率が「何冊で付くのか」を含んでいない。** 含んでいない量を、含んでいるかのように使わない。

### 9.5 次に測るべき量 — **この印が「累計」か「直近」かで、135 万円への意味が正反対になる**

**年間売上は流量（フロー）である。** ところがこの印が**生涯に一度付いたら消えない徽章**なら、
166 冊という数は**過去6年の累積**であって、今年の流量については何も言っていない。
逆に**直近の期間の売上で付け外しされる**なら、166 冊は**いま同時に売れている本の数**に近い。

**同じ数字が、2通りにしか読めないときは、まだ読んでいないのと同じである。**

**判定は時間差でしか取れないので、仮説として登録した（H051）。**
今日の 166 冊の slug 集合を上の TSV に固定してある。**次に測るときの対照はこのファイルである。**
