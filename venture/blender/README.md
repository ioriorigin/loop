# Blender を開かずに、アバターの FBX を直す道具（試作）

VRChat などのアバターの FBX に、**Blender を開かずに**よくある改変を掛ける道具です。
Blender 本体のインストールは要りません。操作はコマンドを1行貼るだけです。

**状態: 試作。** 3つの改変（レシピ）が、Windows・macOS・Linux の検査用の機械で毎回動くことを確かめています
（`.github/workflows/blender-smoke.yml`）。**人の手元でも、実物のアバターでも、まだ試していません。**

## 出来ないこと（先に書きます）

- **個別のサポートはありません。** 困ったときは、下の「困ったとき」の表と、動作確認コマンドの「次にやること」を見てください
- 読めるのは **FBX だけ**です。`.blend`・`.vrm`・`.unitypackage` は読めません
- Unity 側の設定（PhysBone・マテリアル・アバターの設定）は FBX に入らないので、触りません
- 元のファイルは**上書きしません**。結果は必ず別の名前で書き出します。気に入らなければ捨てれば元どおりです

## 導入（初回だけ・5分ほど）

使うのは `uv` という道具1つです。Python も Blender の部品も、`uv` が自動で取ってきます。

**Windows** — スタートメニューで「PowerShell」を開き、次の1行を貼って Enter:

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS** — 「ターミナル」を開き、次の1行を貼って Enter:

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

終わったら、**PowerShell / ターミナルを一度閉じて、開き直してください**（新しく入った `uv` を読み込むため）。

## 動作確認（最初に1回）

この README があるフォルダへ移動します。`cd ` と打って（最後に空白）、フォルダをウィンドウへドラッグし、Enter。
そのあと次の1行を貼ります。

```
uv run --no-project --python 3.11 --with bpy==5.0.1 python doctor.py
```

**初回は約 300MB を取ってくるので、数十秒〜数分かかります。** 2回目からは数秒です。
最後に「すべて ok です」と出れば準備完了です。`NG` が出たら、その行の「次にやること」をやってください。

### 名前を調べる

レシピには「素体の名前」「骨の名前」などを渡します。FBX を後ろに付けて動作確認を実行すると、中の名前が一覧で出ます
（ファイルは読むだけで、書き換えません）。

```
uv run --no-project --python 3.11 --with bpy==5.0.1 python doctor.py アバター.fbx
```

## レシピ

どれも「入力の FBX → 出力の FBX」です。`アバター.fbx` のところには、FBX をウィンドウへドラッグすると正しい場所が入ります。
下の行の先頭の `uv run --no-project --python 3.11 --with bpy==5.0.1 python` は、どのレシピでも同じです。

### 1. 衣装に隠れる素体の面を消す（肌が服を突き抜けるのを止める・ポリゴンを減らす）

```
uv run --no-project --python 3.11 --with bpy==5.0.1 python recipes/hide_body.py アバター.fbx Body 出力.fbx
```

- `Body` は素体のメッシュの名前。素体と衣装を**1つの FBX に入れて**渡します
- 最後に数字を足すと、判定の距離（メートル）を変えられます。既定は `0.03`（3cm）。袖口や襟ぐりの奥が消えすぎたら小さくします

### 2. シェイプキーを左右に分ける（片目だけ閉じる・片頬だけ上げる）

```
uv run --no-project --python 3.11 --with bpy==5.0.1 python recipes/split_shapekey.py アバター.fbx Body 出力.fbx "eye_close,cheek_up"
```

- 分けたいキーの名前をカンマで区切って渡します。`"*"` を渡すと、全部のキーを分けます
- `eye_close_L` と `eye_close_R` ができます。元のキーは残ります。両方を 100 にすると元と同じ形です
- アバターが真ん中（X=0）に立っている前提です

### 3. 骨をウェイトごと分ける（長い髪・スカート・しっぽを、なめらかに曲げる／揺らす）

```
uv run --no-project --python 3.11 --with bpy==5.0.1 python recipes/split_bone.py アバター.fbx Hair 出力.fbx 3
```

- `Hair` を根元から先まで3本に分けます（最後の数字が本数）。1本目は元の名前のまま、`Hair_1`・`Hair_2` が足されます
- 動かしていない姿勢の見た目は変わりません。揺れ物（PhysBone）は Unity 側で分けた骨に付け直してください
- 骨はまっすぐ切ります。曲がった房に沿っては曲げません

各レシピのファイルの先頭に、何をするか・守ること・出来ないことを、もっと詳しく書いてあります。

## 困ったとき

動作確認の `NG` の番号と、同じ番号の行を見てください。

| 番号 | 何が起きたか | 次にやること |
|---|---|---|
| — | `uv` が見つからない（`'uv' は認識されていません` / `command not found`） | PowerShell / ターミナルを閉じて開き直す。それでもだめなら「導入」の1行をもう一度 |
| D1 | Python が 3.11 ではない | 手順の行をそのまま貼る（`--python 3.11` が要る） |
| D2 | bpy が読み込めない | `--with bpy==5.0.1` が入っているか、ネットにつながっているか。初回は約 300MB を取ってくる |
| D3 | FBX の読み書き機能が使えない | `uv cache clean` を実行してから、動作確認をもう一度 |
| D4 | 書き込めない | デスクトップやドキュメントなど、自分のフォルダの下に展開し直す |
| D5 | 日本語の表示が崩れる | 表示だけの問題。レシピはそのまま使える |
| D6 | FBX が見つからない | FBX をウィンドウへドラッグして、正しい場所を入れる |
| D7 | FBX として読めない | Unity や配布元から FBX を書き出し直す（`.blend` `.vrm` は読めない） |
| — | 「〜が見つかりません。ファイルの中のメッシュ: …」 | 名前の打ち間違い。「名前を調べる」で出た名前をそのまま使う |
| — | 「出力先が入力と同じです」 | 出力には別の名前を付ける（元のファイルは上書きしない決まり） |
